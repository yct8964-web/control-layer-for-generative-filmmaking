# License Recommendation

No license is asserted by this draft package. Until the repository owner selects and adds a license, normal copyright protection applies and downstream reuse is not automatically granted.

## Recommended structure

### Documentation and diagrams: CC BY 4.0

Use the Creative Commons Attribution 4.0 International license for Markdown documents, diagrams, specifications, and research notes. It allows sharing and adaptation, including commercial reuse, while requiring attribution and an indication of changes.

Suggested notice after owner approval:

```text
Except where otherwise noted, the documentation and diagrams in this repository
are licensed under the Creative Commons Attribution 4.0 International License.
```

Official license text: https://creativecommons.org/licenses/by/4.0/legalcode

### Future source code: Apache License 2.0

If implementation begins, license source code under Apache License 2.0. It is a widely used permissive software license that includes an explicit patent grant and clear notice requirements.

Suggested notice after owner approval:

```text
Source code in this repository is licensed under the Apache License, Version 2.0,
except where otherwise noted.
```

Official license text: https://www.apache.org/licenses/LICENSE-2.0

## Files to add after confirmation

To avoid ambiguity in a mixed documentation/code repository:

1. add the full CC BY 4.0 text as `LICENSE-DOCS`;
2. add the full Apache-2.0 text as `LICENSE-CODE` when code first appears;
3. add a short root `LICENSE` or `NOTICE` explaining which files each license covers;
4. add SPDX identifiers to future source files where practical; and
5. record third-party assets and their licenses separately.

This is a publishing recommendation, not legal advice. The owner should confirm the final choice before public release.
